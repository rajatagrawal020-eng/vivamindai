# VivaMind AI

Create a modern, production-ready AI SaaS web application called “VivaMind AI”.

The platform should help students prepare for viva exams, interviews, oral exams, practicals, and rapid-fire questioning using AI.

Core Vision

This should NOT feel like a generic chatbot.

It should feel like a specialized AI preparation platform for:

Engineering students

Medical students

Civil services aspirants

Commerce students

School students

Coding interview preparation

The UI must look premium, modern, clean, fast, and mobile responsive.
